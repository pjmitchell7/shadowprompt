The Problem

Covert Token Smuggling

Attackers inject zero-width Unicode characters (such as U+200B and U+200C) or Right-to-Left overrides into documents, RAG pipelines, and user prompts. Human reviewers see normal text, but model tokenizers parse and execute the covert jailbreak instructions.

The Industry Flaw

The 800ms Guardrail Trap

Enterprise teams deploy secondary LLMs (Llama Guard, NeMo) to validate every prompt. This introduces fatal latency, doubles GPU compute expenses, and remains blind to byte-level steganography because model tokenizers strip invisible characters before inspection.

The ShadowPrompt Fix

In-Memory Bitstream Defense

ShadowPrompt executes entirely in memory at the edge or middleware layer in 0.05ms. It evaluates raw Unicode streams, unpacks steganographic bitstreams, reverses leetspeak, plants honey canaries, and emits STIX 2.1 alerts before the prompt ever touches a GPU.
